# Brain 3D model attribution

## Primary mesh

**File:** `brain.glb` (Draco-compressed glTF)

**Source project:** [Brain Project](https://github.com/itayinbarr/brainproject) by Itay Inbar  
**Upstream anatomy:** structures derived from open atlases including Z-Anatomy / BodyParts3D and registered imaging atlases (see project docs).  
**License (3D assets):** [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)  
**Code license of upstream project:** Apache-2.0 (does not apply to this site’s own HTML/JS beyond fair use of the mesh).

This educational site hosts a copy of `brain.glb` for GitHub Pages. Region highlights map named submeshes to consciousness-discussion labels (thalamus, PFC, posterior hot zone, brainstem, DMN hubs, ACC, insula). The **claustrum** is not a separate mesh in the source atlas; a thin educational marker is placed near the putamen–insula interface.

## Draco decoder

`draco/` and `draco/gltf/` decoder files are from the [three.js](https://github.com/mrdoob/three.js) examples (Draco by Google), used to decode the compressed mesh in-browser.

## Disclaimer

Educational visualization only — not for clinical use. Gross-anatomy grade surfaces; deep nuclei are approximate.
